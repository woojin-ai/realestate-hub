- **실브라우저 360/768/1280px 렌더 실측**: 스크린샷 도구 불안정으로 미수행. CSS 규칙(`keep-all`/`overflow-wrap`) + 최장 무공백 토큰 7자 산술로 대체 판정했다. **실측이 아니라 코드 기준 판정임을 명시한다.**
- **스크린리더 실청취**: 미수행. 링크 텍스트 8종(7~18자)이 전부 목적지를 식별하는 명사구이고 §4-2 금지 텍스트(`여기`·`이 글`·`자세히 보기` 등) 0건임을 문자열 검사로 확인한 것까지가 범위다.
- **빌드 게이트 역검증**(스펙 §8-15·§8-16: 없는 slug/자기링크/`{text,segments}` 동시지정을 넣어 빌드가 죽는지) — **미수행.** 코드를 수정하지 말라는 지시와 충돌한다. 1단계 라운드에서 수행됐는지는 이번에 확인하지 않았다. **미확인 항목으로 남긴다.**
- `docs/planning/content-strategy.md` §7-3·§7-6(출처 표기 위치 분리)은 이번 변경이 `sourceLinks`를 건드리지 않으므로 대조 불필요로 판단했다.

## 11. 커밋 시 마스터께 드리는 사항 — **경로 지정 커밋**

**작업 트리에 이번 라운드 대상이 아닌 변경이 함께 올라와 있다.** `git add -A`를 쓰면 아래가 전부 쓸려 들어간다.

| 항목 | 성격 |
|---|---|
| `lib/db-cache.ts` · `lib/molit-api.ts` · `supabase/schema.sql` | 🔴 **동결 3파일** (13라운드째 미커밋 대기, mtime 2026-07-25) |
| `.claude/settings.json` | 미추적. 커밋 대상 아님 |
| `docs/design/sample-floor-disclosure-spec-2026-08-04.md` | 라운드59 §8-6 문서 정정 숙제 — **마스터가 직접 처리한 별건 변경**(검증 중 mtime 01:37 갱신). 사고 아님·티켓 #18 무관. 이번 커밋에 묶을지는 마스터 판단 |

따라서 커밋은 반드시 **경로 지정**으로:

```
git add lib/blog.ts docs/planning/blog-inline-links-phase2-copy-2026-08-05.md docs/qa/blog-inline-links-phase2-verification-2026-08-05.md
```

> **[정정 이력]** 이 절의 초판은 `sample-floor-disclosure-spec` 변경을 "티켓 #18(스케줄 회차 동시 실행 경합) 재발"로 판정했으나 **오진이었다.** 마스터가 QA 검증과 병행해 라운드59의 문서 정정 숙제를 처리한 것이며, 동시 편집 사고가 아니다. 경로 지정 커밋 권고 자체는 동결 3파일·미추적 파일 때문에 그대로 유효하다.
