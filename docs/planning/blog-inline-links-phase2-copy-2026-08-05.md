## 6. 마스터께 올리는 사항

1. **디자인팀 스펙의 앵커 오기 1건을 정정했다(#17).** `:231`은 +17 시프트 후 **리스트 항목**이라 그대로 구현하면 §5-2 위반이 된다. `:230` 문단으로 옮겼고 근거는 §3-7에 적었다. 나머지 8개 앵커는 전부 +17로 정확히 맞았다 — **단순 오기로 판단하며 스펙의 다른 판단을 의심할 근거는 못 찾았다.**
2. **I1이 상한 3에 도달한다.** 셋 다 근거가 있어 전부 채택했지만, 3개가 원칙 3·4·5 **연속 세 문단**에 몰려 시각적으로 밀집한다. 부담스러우시면 **#11을 먼저 빼는 것**을 권고한다(사유 §1-2). 뺄 때 다른 두 쌍은 영향받지 않는다.
3. **가시텍스트가 +436자 늘어난다 — 1단계의 합격 기준이 이번에는 적용되지 않는다.** 읽기시간 표시가 일부 글에서 1분 바뀔 수 있고, 콘텐츠 재검수(QA 축자 게이트 + YMYL)가 **필요한 라운드**다.
4. **새 표현을 발명하지 않았다.** 8개 새 문장이 전부 `…는 <명사구>을 다룬 글에서 따로 정리/설명했습니다` 한 가지 정형구다. 이 정형구는 축자 게이트 예외 ①로 이미 확정돼 있고 발행본 I3·H4·I4가 쓰는 것과 같다. **이 정형구를 이후 라운드의 기본값으로 확정할지** 확인 요청드린다(확정되면 다음 편 집필 시 문안 협의가 사라진다).
5. **2단계까지 반영하면 수신 0인 글은 M1 하나만 남는다.** (스펙 §6-2는 "G2·H3·M1·M2·M4"라고 적었으나 #15가 G2를, #18이 H3를 수신처로 만든다. M2·M4는 `market`이라 §6-3이 의도적으로 배제한 것이고, M1은 §6-3이 "억지 연결을 만들지 않는다"며 명시적으로 제외했다.) **M1을 그대로 고립시킬지**는 마스터 판단으로 남긴다 — 기획팀 권고는 §6-3 유지(억지 연결 배제)다.
